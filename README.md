## 🚀 Installation

### **Method 1: GitHub Integration (Recommended)**

1. **Connect GitHub to Shopify:**
   ```
   Shopify Admin → Online Store → Themes → Add Theme → Connect from GitHub
   ```

2. **Select Repository:**
   - Repository: `umaiskhan-ops/luxora-timeless-theme`
   - Branch: `main`

3. **Auto-Deploy:**
   - Changes pushed to GitHub automatically sync to Shopify

### **Method 2: Manual Upload**

1. Download the `shopify-theme` folder
2. Zip all files inside (not the folder itself)
3. Upload to Shopify: `Themes → Upload theme`
